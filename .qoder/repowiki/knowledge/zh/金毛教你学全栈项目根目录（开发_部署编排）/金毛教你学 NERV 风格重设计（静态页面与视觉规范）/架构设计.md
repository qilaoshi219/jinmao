模块以纯静态 HTML + CSS 构成，无构建系统：
- `colors_and_type.css` 定义全局 `--nerv-*` CSS 变量（明/暗双主题），作为所有页面的设计令牌来源。
- `pages/` 下每个 `.html` 文件自包含完整页面，通过 `<style id="theme-vars">` 内联复制同一份 CSS 变量，并借助 Tailwind CSS Browser v4（CDN）和 Lucide 图标库渲染 UI。
- `jinmao-nerv-redesign.design` 是可视化编辑器元数据，声明三个页面节点（login-v2 / home-v2 / study）及其 DOM 交互边（如 `login-submit → page-home-v2`）。
- `orchestration-summary.json` 记录项目意图、设计调参（layoutVariance/motionIntensity/visualDensity）与共享 Shell 契约（主色、字体栈、圆角、表面模型）。
- `validation-report.json` 由 solo-design skill 生成，用于校验页面数量与交互完整性。
- `.preflight/preflight.html` 配合 `fill-html-head.mjs` 脚本注入 CSS 变量进行预检。
依赖方向单向：HTML 页面 → CSS 变量 → Tailwind/Lucide CDN；`.design` 与 `orchestration-summary.json` 仅被外部评估工具读取，不反向影响页面。
