该模块为纯测试资源目录，无代码依赖关系，按用途划分为三类：
- 自动化脚本：`e2e-test.ps1` 通过 PowerShell 调用后端 `/api/v1` 接口完成邮箱验证码登录、PDF 教材上传、流水线状态轮询的完整端到端流程；`code/minio-crud.js` 使用 Node.js minio 客户端对本地 MinIO 执行 bucket 检查、对象增删改查。
- 测试样本数据：根目录下包含多种格式的教材与试题（`.pdf`、`.docx`、`.json`、`.md`、`.zip`），用于驱动教材解析、题库转换、Word/PDF 导出等功能验证。
- 辅助临时目录：`_temp\_zip_src` 提供带子目录结构的 ZIP 解压源样例；`金毛刷题\backend`、`frontend`、`pyapi` 等为被测系统的前后端及 Python 服务源码，供 E2E 脚本直接连接运行。
依赖方向单向向下：脚本仅依赖外部服务（MySQL、MinIO、DeepSeek、Doc2x、TTS）和 HTTP API，不反向依赖被测业务逻辑。
