- 每个外部 API 独立一个 Markdown 文件，按“基础信息 → 鉴权 → 接口定义 → 请求/返回示例 → 错误码”的结构组织。
- 接口文档同时提供 bash curl 和 Python requests 两种调用示例，便于快速验证。
- 认证统一通过 HTTP Header 传递，如 Doc2x 使用 `Authorization: Bearer sk-xxx`，豆包 TTS 使用 `X-Api-App-Id` / `X-Api-Access-Key` / `X-Api-Resource-Id` 等多头组合。
- 异步任务均采用“触发接口 + 轮询 status/result 接口”的两阶段模式，并在文档中明确轮询频率建议。
