采用经典的三层架构：`API/` 目录按业务域划分路由模块（book、course、quiz、auth、billing、progress、stats、files），每个子模块通过 `index.js` 统一聚合子路由；`service/` 层封装业务逻辑（auth、md2quiz、POSTbook、course_pipeline、quiz_* 等），`utils/` 提供共享工具（prisma 单例、jwt、llm_client、upload_minio、doc2x 等），`repo/` 存放数据库仓储操作。入口 `app.js` 负责启动前自检（.env 校验、Prisma Client 自动生成与 schema 哈希比对、数据库迁移版本控制）、挂载中间件（helmet、cors、日志）、注册所有路由并启动 HTTP 服务器。配置集中由 `config/index.js` 加载各 JSON 配置文件并从 `.env` 注入敏感字段。数据库模型定义在 `prisma/schema.prisma`，迁移文件位于 `prisma/migrations/`。异步任务（如 MD→Quiz 生成）通过 `service/md2quiz/` 下的 task-store、task-runner、task-stream-broker 等模块实现内存+文件持久化的任务队列。
