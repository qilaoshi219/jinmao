- 每个业务域的路由模块通过 `index.js` 统一聚合子路由，再被 `app.js` 以 `app.use("/api/v1", router)` 形式挂载到统一前缀下
- 服务层模块通过 `index.js` 重新导出拆分前的函数签名，保持对外接口向后兼容
- 所有敏感配置（API Key、数据库连接串等）仅从 `process.env` 读取，JSON 配置文件中只保留非敏感字段
- 数据库访问统一通过 `utils/prisma.js` 导出的单例实例，避免重复创建连接池
- 错误响应统一返回 `{ code, message }` 结构，鉴权失败返回 401，未捕获异常由全局错误中间件返回 500
- 模块内部使用 `const TAG = "[模块名]"` 作为日志前缀，便于区分不同模块的输出
