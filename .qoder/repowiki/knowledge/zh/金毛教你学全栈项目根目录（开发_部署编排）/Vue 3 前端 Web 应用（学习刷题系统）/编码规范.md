- API 模块按业务域拆分为独立文件（auth.js、books.js、quiz.js 等），统一通过 `src/api/client.js` 导出的 axios 实例发起请求。
- Pinia Store 使用 Composition API 风格定义（`defineStore('name', () => {...})`），state/getter/action 均以 ref/computed/function 形式组织。
- 页面组件采用 `.vue` 模板与同目录 `script.js` 分离的写法，便于大文件逻辑拆分。
- 日志输出统一使用 `const TAG = '[模块名]'` 前缀拼接 console.log/warn/error，便于调试定位。
- 暗黑模式通过 `html.dark` class 驱动，Tailwind 的 `dark:` 变体与 Element Plus 的 CSS 变量方案共用同一触发器。
- Token 持久化通过 `utils/storage.js` 的 `getToken/setToken/removeToken` 封装，Store 中登录成功后同时更新内存状态和 localStorage。
