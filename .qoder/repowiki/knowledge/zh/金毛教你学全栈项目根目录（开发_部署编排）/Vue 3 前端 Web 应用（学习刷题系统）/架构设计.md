采用典型的 Vue 3 单页应用分层结构：
- 入口层：`src/main.js` 创建 Vue 应用实例并挂载 Pinia；`src/App.vue` 作为根组件根据登录态和 `currentPage` 状态切换页面。
- 路由层：无独立路由库，使用 App 组件内的 `ref('home'|'study'|'quiz'|'billing')` 配合 `provide/inject` 实现轻量级页面导航。
- 页面层：`src/pages/` 按业务域划分（home、login、study、quiz、billing），每个页面由 `.vue` 模板与同目录 `script.js` 分离逻辑。
- 组件层：`src/components/` 存放可复用 UI 组件，其中 `components/quiz/` 子目录专门封装各类题型组件（选择题、填空题、判断题等）。
- 状态管理：`src/stores/auth.js` 使用 Pinia Composition API 风格定义认证 Store，管理 Token 和用户信息。
- API 层：`src/api/` 按模块拆分接口（auth、books、quiz、progress、stats、billing、client），统一通过 `axios` 实例发起请求。
- 工具层：`src/composables/` 提供组合式函数（useTheme、useResize），`src/utils/storage.js` 封装 localStorage 操作。
- 样式层：Tailwind CSS v4 + Element Plus 暗黑模式双轨同步，通过 `html.dark` class 驱动主题切换。
- 构建配置：`vite.config.js` 集成 Vue SFC、Tailwind、Element Plus 按需自动导入插件，开发端口 30000，`/api` 代理至后端 8888。
