# 前端暗黑模式规范手册

> 版本：v1.0 | 最后更新：2026-07-06
>
> 适用于：金茂教材处理系统 前端项目（Vue 3 + Tailwind CSS v4 + Pinia）

---

## 1. 概述

### 1.1 规范目的

本手册定义前端暗黑模式（Dark Mode）的技术架构和开发规范，确保：
- 所有新增页面 **从第一天起** 就支持暗黑模式
- 所有开发者用 **统一的方式** 编写主题适配代码
- 不依赖手搓代码，全部使用 **成熟的开源方案**

### 1.2 适用范围

| 范围 | 说明 |
|------|------|
| **强制遵循** | 所有新增/重构的 `.vue` 页面组件 |
| **建议遵循** | 已有页面（可逐步改造） |
| **无需关注** | 纯逻辑文件（`.js` composables、stores、utils） |

### 1.3 技术栈

| 层级 | 技术 | 版本 | 角色 |
|------|------|------|------|
| 状态管理 | `@vueuse/core` - `useDark` | ^13 | 管理暗黑模式状态、localStorage 持久化、系统偏好检测 |
| 样式引擎 | Tailwind CSS v4 - `dark:` 变体 | ^4.3 | 原子级样式切换，`class` 策略 |
| 基础层 | CSS 自定义变量 | 原生 | Tailwind 覆盖不到的场景（body 背景等） |
| 兜底 | `prefers-color-scheme` | CSS Level 5 | JS 不可用时的系统跟随 |

## 2. 技术架构

### 2.1 三层架构

```
┌──────────────────────────────────────────────────────┐
│           第3层：VueUse useDark（状态管理）            │
│   · 管理响应式布尔值 isDark                           │
│   · 自动持久化到 localStorage（刷新不丢失）            │
│   · 首次访问自动检测系统 prefers-color-scheme         │
│   · 提供 toggleTheme() 切换函数                       │
├──────────────────────────────────────────────────────┤
│         第2层：Tailwind CSS v4 class 策略（样式）       │
│   · dark: 变体检测 html 上的 .dark class              │
│   · 所有组件统一使用 dark: 前缀切换颜色                │
│   · 构建时自动 tree-shake 未使用的 dark 样式           │
├──────────────────────────────────────────────────────┤
│           第1层：CSS 变量（基础层/Fallback）            │
│   · 定义 --color-bg-primary 等全局变量                │
│   · .dark 选择器覆盖暗黑值                             │
│   · prefers-color-scheme 作为 JS 不可用时的兜底        │
└──────────────────────────────────────────────────────┘
```

### 2.2 数据流

```
用户点击切换按钮
  ↓
VueUse toggleTheme() 被调用
  ↓
isDark Ref 值反转（true ↔ false）
  ↓
useDark 内部自动操作 html 元素 class:
  · isDark=true  → html.classList.add('dark')
  · isDark=false → html.classList.remove('dark')
  ↓
Tailwind CSS 的 dark: 变体检测到 html.dark
  ↓
所有 dark:xxx 工具类立即生效
  ↓
同时，CSS 变量在 .dark 选择器下的值也切换到暗色
  ↓
用户看到整个页面颜色平滑过渡（transition 200ms）
```

### 2.3 关键文件

| 文件 | 职责 |
|------|------|
| `src/composables/useTheme.js` | 封装 `useDark` + `useToggle`，导出 `isDark` 和 `toggleTheme` |
| `src/styles/index.css` | 全局样式入口，配置 `@custom-variant dark`，导入 tokens.css |
| `src/styles/tokens.css` | 定义 `:root` 和 `.dark` 两套 CSS 变量 |

## 3. 环境配置（一次性，已完成）

以下配置已在项目中完成，**新开发者无需重复配置**。

### 3.1 Tailwind CSS v4 class 策略

在 `src/styles/index.css` 中：

```css
@import "tailwindcss";

/* 切换到 class 策略：手动控制暗黑模式 */
@custom-variant dark (&:where(.dark, .dark *));
```

- `@custom-variant` 是 Tailwind v4 的自定义变体语法
- `&:where(.dark, .dark *)` 表示：当当前元素或其任意祖先有 `.dark` class 时生效

### 3.2 主题 Composable

在 `src/composables/useTheme.js` 中：

```js
import { useDark, useToggle } from "@vueuse/core"

export function useTheme() {
  const isDark = useDark({
    selector: "html",
    valueDark: "dark",
    valueLight: "",
    storageKey: "app-theme",
  })
  const toggleTheme = useToggle(isDark)
  return { isDark, toggleTheme }
}
```

### 3.3 CSS 变量

在 `src/styles/tokens.css` 中：

```css
:root {
  --color-bg-primary: #f9fafb;
  --color-bg-secondary: #ffffff;
  --color-text-primary: #1f2937;
  --color-text-secondary: #6b7280;
  --color-border: #e5e7eb;
}

.dark {
  --color-bg-primary: #111827;
  --color-bg-secondary: #1f2937;
  --color-text-primary: #f3f4f6;
  --color-text-secondary: #9ca3af;
  --color-border: #374151;
}
```

## 4. 组件开发规范

### 4.1 核心原则：每行都要有 `dark:` 对应

**规则：任何包含颜色的 Tailwind 类，必须同时写上 `dark:` 变体。**

```html
<!-- ✅ 正确示例 -->
<div class="bg-white dark:bg-gray-800 text-gray-900 dark:text-gray-100">
  内容区域
</div>

<!-- ❌ 错误示例：只有亮色，暗黑模式下不变 -->
<div class="bg-white text-gray-900">
  内容区域
</div>

<!-- ❌ 错误示例：只有暗色，亮色模式下不变 -->
<div class="dark:bg-gray-800 dark:text-gray-100">
  内容区域
</div>
```

### 4.2 常用颜色映射表

以下是 Tailwind 亮色 → 暗色的推荐对应关系：

| 用途 | 亮色类（默认） | 暗色类（dark:） | 说明 |
|------|---------------|-----------------|------|
| **页面背景** | `bg-gray-50` | `dark:bg-gray-900` | 主背景 |
| **卡片/容器背景** | `bg-white` | `dark:bg-gray-800` | 内容卡片 |
| **次级容器背景** | `bg-gray-100` | `dark:bg-gray-700` | 输入框、标签等 |
| **主文字** | `text-gray-900` | `dark:text-gray-100` | 标题、正文 |
| **次级文字** | `text-gray-500` | `dark:text-gray-400` | 描述、辅助信息 |
| **浅色文字** | `text-gray-400` | `dark:text-gray-500` | 占位符、水印 |
| **边框** | `border-gray-200` | `dark:border-gray-700` | 分割线、卡片边框 |
| **浅色边框** | `border-gray-100` | `dark:border-gray-800` | 内部分割线 |

#### 彩色语义色映射

| 色调 | 亮色类 | 暗色类 | 用途 |
|------|--------|--------|------|
| **蓝色** | 文本 `text-blue-600`，背景 `bg-blue-50` | 文本 `dark:text-blue-400`，背景 `dark:bg-blue-900/30` | 链接、信息 |
| **绿色** | 文本 `text-green-600`，背景 `bg-green-50` | 文本 `dark:text-green-400`，背景 `dark:bg-green-900/30` | 成功状态 |
| **红色** | 文本 `text-red-600`，背景 `bg-red-50` | 文本 `dark:text-red-400`，背景 `dark:bg-red-900/30` | 错误/危险 |
| **黄色** | 文本 `text-yellow-600`，背景 `bg-yellow-50` | 文本 `dark:text-yellow-400`，背景 `dark:bg-yellow-900/30` | 警告 |

### 4.3 阴影在暗黑模式下的处理

暗黑模式下阴影效果会减弱（因为背景本身是暗的），推荐使用不同的阴影：

```html
<!-- ✅ 推荐：两套阴影 -->
<div class="shadow-sm dark:shadow-md shadow-gray-200 dark:shadow-black/30">
</div>

<!-- ✅ 简化版：暗黑模式直接去掉阴影 -->
<div class="shadow-sm dark:shadow-none">
</div>
```

### 4.4 图片/图标适配

```html
<!-- SVG 图标：通过 text 颜色控制 -->
<svg class="w-5 h-5 text-gray-600 dark:text-gray-300">...</svg>

<!-- 位图：如果暗黑下需要不同的图片 -->
<img
  :src="isDark ? '/img/logo-dark.png' : '/img/logo-light.png'"
  alt="Logo"
/>
```

### 4.5 过渡动画

**所有可切换主题的组件** 应该添加 `transition-colors` 类：

```html
<!-- ✅ 推荐：添加颜色过渡 -->
<div class="bg-white dark:bg-gray-800 transition-colors duration-300">
  内容
</div>

<!-- ✅ 交互元素也加上过渡 -->
<button class="bg-blue-500 dark:bg-blue-600 hover:bg-blue-600 dark:hover:bg-blue-500 transition-colors duration-200">
  按钮
</button>
```

### 4.6 完整组件示例

```vue
<template>
  <!-- 卡片组件：完整暗黑模式适配示例 -->
  <div class="
    bg-white dark:bg-gray-800
    border border-gray-200 dark:border-gray-700
    rounded-lg
    shadow-sm dark:shadow-md dark:shadow-black/20
    p-6
    transition-colors duration-300
  ">
    <!-- 标题 -->
    <h2 class="text-lg font-semibold text-gray-900 dark:text-gray-100 mb-2">
      卡片标题
    </h2>

    <!-- 描述 -->
    <p class="text-sm text-gray-500 dark:text-gray-400 mb-4">
      卡片描述文字
    </p>

    <!-- 操作按钮 -->
    <button class="
      px-4 py-2
      bg-blue-500 dark:bg-blue-600
      text-white
      rounded-md
      hover:bg-blue-600 dark:hover:bg-blue-500
      transition-colors duration-200
    ">
      确认
    </button>
  </div>
</template>
```

## 5. 主题切换 UI 规范

### 5.1 切换按钮

使用 `useTheme` composable 创建切换按钮：

```vue
<script setup>
import { useTheme } from "@/composables/useTheme"
const { isDark, toggleTheme } = useTheme()
</script>

<template>
  <button
    @click="toggleTheme()"
    class="p-2 rounded-lg bg-gray-100 dark:bg-gray-700 text-gray-600 dark:text-gray-300 hover:bg-gray-200 dark:hover:bg-gray-600 transition-colors duration-200"
    :title="isDark ? '切换到亮色模式' : '切换到暗黑模式'"
  >
    <!-- 暗黑模式：显示太阳图标（切回亮色） -->
    <svg v-if="isDark" class="w-5 h-5" ...><!-- 太阳图标 SVG --></svg>
    <!-- 亮色模式：显示月亮图标（切到暗色） -->
    <svg v-else class="w-5 h-5" ...><!-- 月亮图标 SVG --></svg>
  </button>
</template>
```

### 5.2 切换动画

全局过渡已在 `tokens.css` 中配置（`html` 上 `transition: background-color 0.2s ease, color 0.2s ease`）。组件级别使用 `transition-colors duration-300` 即可。

### 5.3 图标选择

推荐使用 Heroicons 风格的 SVG 内嵌图标（无需额外依赖）：

- 亮色模式 → 显示 **月亮** 图标（暗示"点击进入暗黑"）
- 暗黑模式 → 显示 **太阳** 图标（暗示"点击回到亮色"）

| # | 检查项 | 说明 |
|---|--------|------|
| ☐ | 所有背景色有 `dark:` 对应 | `bg-white` → `dark:bg-gray-800` 等 |

| ☐ | 在 Chrome DevTools 中手动切换 `.dark` 验证 | Elements → `<html>` → 右键 → Add/Edit class |

## 7. 常见问题

### Q: 为什么某个元素暗黑模式下颜色不对？

**A:** 检查步骤：
1. 打开 Chrome DevTools → Elements
2. 在 `<html>` 上右键选择 "Force state" → `:root .dark`（或手动加 class）
3. 选中出问题的元素，查看 Computed Styles
4. 检查是否缺少 `dark:` 前缀的对应类
5. 检查是否有其他样式覆盖（如内联 style）

### Q: 如何自定义暗黑颜色？

**A:** 优先使用 Tailwind 内置色阶（gray-100 ~ gray-900）。如果确实需要自定义颜色，在 Tailwind v4 中用 `@theme` 指令：

```css
/* 在 src/styles/index.css 的 @import "tailwindcss" 之后 */
@theme {
  --color-brand-50: #eff6ff;
  /* ... */
  --color-brand-900: #1e3a5f;
}
```

然后在组件中使用 `bg-brand-50 dark:bg-brand-900`。

### Q: 切换到暗黑模式后刷新页面，主题会丢失吗？

**A:** 不会。VueUse `useDark` 会自动将状态持久化到 `localStorage`，键名为 `app-theme`。刷新后自动恢复。

### Q: 用户从不手动切换，默认是什么模式？

**A:** `useDark` 首次访问时会读取系统的 `prefers-color-scheme` 偏好。如果操作系统是暗黑模式，默认就是暗黑；否则是亮色。

### Q: 为什么不用 `prefers-color-scheme` 媒体查询？

**A:** 媒体查询只能跟随系统，用户无法在网页内手动切换。我们使用 media 查询仅作为 JS 不可用时的 fallback（见 `tokens.css` 第43-49行）。
