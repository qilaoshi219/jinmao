### 技术要点
- **布局**：全屏 flex 行布局（无 max-w 限制），侧边栏 252px 固定宽，<860px 自动收缩至 84px
- **API 对接**：`listBooks()`（GET /books，code:0）、`uploadBook()`（POST /book/upload）、`getBookStatus()`（GET /book/:id/status）、`getProfile()`（GET /auth/profile）
- **状态轮询**：有处理中的教材时每 3s 自动刷新列表，全部完成自动停止
- **骨架屏**：加载中显示 6 个自定义 animate-pulse 占位卡片
- **空状态**：无教材时显示虚线边框 + SVG 空图标提示
- **设计规范**：所有组件严格遵守 text-black/dark:text-white、rounded-[10px]、duration-500、暗黑双轨适配
- **文件行数**：所有新建文件均控制在 300 行以内

## 2026-07-06 - 登录页视觉美化设计

### 修改原因
登录页已完成 design-spec 结构性重构（Element Plus + dark: 双轨），但视觉上较为朴素，缺乏品牌感和视觉层次。

### 美化内容

| 美化点 | 实现方式 |
|--------|----------|
| 背景装饰 | 两个大尺寸蓝色渐变光晕（右上角 + 左下角），暗黑模式下透明度更高 |
| Logo 品牌区 | 蓝色圆形背景 + 书本 SVG 图标，带蓝色阴影光晕 |
| 卡片装饰 | 顶部蓝色渐变装饰条（`h-1`）+ 标题下蓝色分割线 |
| 输入框图标 | `el-input` 的 `#prefix` 插槽：邮箱图标（Message）+ 锁图标（Lock） |
| 表单分区 | 邮箱区和验证码区各自用浅灰背景 `bg-gray-50` 包裹，视觉分区清晰 |
| 入场动画 | 卡片 fade-in + slide-up（500ms），内联 `<style scoped>` 实现 |
| 响应式按钮 | 手机端竖排（按钮在输入框下方全宽）、桌面端横排 |
| 按钮统一 | 登录按钮改为 `type="primary"` 蓝色，与整体风格统一 |

### 修改文件

| 文件 | 操作 | 说明 |
|------|------|------|
| `src/pages/login/index.vue` | 重写 | 全面美化：背景装饰、Logo区、卡片装饰、输入框图标、入场动画 |
| `package.json` | 修改 | 新增依赖 `@element-plus/icons-vue`（Element Plus 官方图标库） |

### 不修改的文件

- `script.js` — 逻辑无变化，仅模板美化
